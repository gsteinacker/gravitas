## Ziel

Nutzerbeobachtung: Die Spiralstruktur der großen Galaxien (Szene 5) fehlt fast vollständig.

## Akzeptanzkriterien

- [x] Ursache gemessen (m=2-Amplitude A₂, σ_R, Toomre-Q): Start mit Q = 0,55 (zu kalt), sofortige Aufheizung 22 → 59 km/s in 0,1 Gyr. Danach weitere numerische Aufheizung durch schwere DM-Teilchen (N-abhängig).
- [x] Toomre-Anfangsbedingungen (Q, Epizykel, isotherme Scheibe, Asymmetric Drift, Hernquist 1993) und eine junge, kalte Population (`coldFraction`): Q am Start 1,12, A₂ innen 0,07–0,13 → 0,18–0,26
- [x] Automatische Belichtung: Die Scheiben waren zu Weiß gesättigt, Arme dadurch unsichtbar
- [x] Sichtprüfung: Milchstraße zeigt einen Balken mit Ring- und Armstruktur, M51 Gezeitenarme und Brücke

## Notizen
- Bleibende Grenze: Reine Sternscheiben heizen auf (Q → 1,7–2,2 in 1,5 Gyr), Arme bleiben kontrastarm. Echte Galaxien halten Arme durch Gas, Kühlung und Sternentstehung aufrecht (siehe Diskussion Gas/Staub).
