# ADR schreiben

1. Nächste Nummer aus `ls docs/adr` bestimmen, Datei `docs/adr/NNNN-kebab-titel.md` aus `0000-template.md` anlegen.
2. Kontext, Entscheidung, **mindestens zwei ernsthafte Alternativen** und Konsequenzen ausfüllen, auf Deutsch.
3. Ersetzt der ADR einen älteren: dort `Status: superseded by ADR-NNNN` setzen.
4. Betroffene Docs (`docs/physics.md`, `docs/architecture.md`) und Tasks nachziehen.
